# Simplifying Compliance for Research Analysts

A pixel-perfect, fully responsive landing page built from a high-fidelity Figma design. This project demonstrates precise UI implementation, adherence to an 8pt grid system, and mobile-first responsiveness.

## 🔗 Live Links
- **Live Demo:** https://pixel-perfect-assignment.vercel.app/
- **GitHub Repository:** https://github.com/2608raghav/pixel-perfect-assignment.git

## 🎯 Project Overview
The objective was to convert a complex Figma design into a static HTML/CSS page with **zero visible difference** from the original source. Every element—from typography and spacing to button interactions—has been tuned to match professional "Pixel Perfect" standards.

### Key Requirements Met:
- [cite_start]**Pixel-Perfect Accuracy**: All measurements (padding, margin, width, height) match the Figma Inspect panel exactly [cite: 1-8].
- [cite_start]**8pt Grid System**: Used consistent spacing (8px, 16px, 24px, 32px) to ensure visual balance [cite: 203-217].
- [cite_start]**Fully Responsive**: The layout adapts seamlessly from 1440px Desktop to 375px Mobile [cite: 614, 630-637].
- **Clean Code**: Semantic HTML5 tags and well-commented CSS for professional maintainability.

## 🛠️ Tech Stack
- **HTML5**: Semantic structure.
- **CSS3**: Custom variables, Flexbox, and Grid layout.
- **Figma**: Source of design truth and asset extraction.
- **Vercel**: Hosting and continuous deployment.

## 📐 Design Implementation Details
- [cite_start]**Typography**: Matched font-weights and precise line-heights to ensure identical rendering to the design [cite: 274-280, 360-365].
- [cite_start]**Color Palette**: Exact HEX codes used for brand consistency (Primary Blue: `#4856D1`) [cite: 58-61, 435].
- **Asset Optimization**:
  - [cite_start]**Icons**: Exported as SVGs for infinite scalability [cite: 18-29].
  - [cite_start]**Illustrations**: Exported at 2x resolution for sharpness on high-density displays [cite: 49-51, 180-185].
- [cite_start]**Mobile Experience**: Navigation links remain permanently visible and stack vertically for ease of use on mobile devices [cite: 630-637].
